Add Stack, Inline, Heading, Text, Form, and FormActions, so pages need no native tags. Progress can take its color from `ranges`, and `fill` can be solid, gradient, or segments. StatGroup has visible dividers and the same height for each number. Select has a `native` option. Add ImageInput and compressImage, which compress images in the browser. The default theme is now neutral: black, white, and gray, with color only for status and charts.
